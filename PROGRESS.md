### AI-провайдеры (переключатель в ⚙️ Ещё → «🧠 AI-провайдер»)
- Kimi (по умолчанию, блок ниже как раньше) / OpenAI / Claude / Gemini.
- Настройки: localStorage 'kuda_ext' {provider, keys, models}.
- Реализация: ext.js оборачивает window.fetch — запросы app.js на
  api.moonshot.ai транслируются в формат выбранного провайдера (и ответ обратно
  в OpenAI-формат). app.js НЕ ТРОГАЕМ — все расширения только через ext.js.
- Модели по умолчанию: gpt-4o-mini, claude-haiku-4-5-20251001, gemini-2.0-flash.
- При выборе не-Kimi провайдера ext ставит S.kimiKey='ext-managed' (иначе app
  не отправляет фото). «Проверить ключ» приложения проверяет выбранного.
- Anthropic из браузера требует заголовок anthropic-dangerous-direct-browser-access (есть).

### Архитектурное правило
app.js (ядро) не редактируем — большой и опасно. Всё новое — в ext.js или
новые файлы-модули. Вкладки: switchTab(name) универсален — новая кнопка
data-tab + section#tab-<name> работают без правок app.js.

# KUDA — памятка проекта (читать новому чату Kimi в первую очередь)

## Что это
PWA-приложение учёта расходов «KUDA» (куда уходят деньги).
Живёт по адресу: https://vizumsystemsale.github.io/kuda/
Хостинг: GitHub Pages из ветки main этого репозитория (бесплатно).
Репозиторий: https://github.com/VizumSystemSale/kuda (владелец вошёл через GitHub-аккаунт VizumSystemSale).

## Структура файлов
- index.html — каркас + весь CSS (тёмный премиум, акцент #2EE6A8), подключает app.js
- app.js — ВСЯ логика (~31 КБ)
- sw.js — service worker, кэш kuda-v2 (при смене файлов поднимать версию!)
- manifest.webmanifest — имя KUDA, иконка icon.svg
- icon.svg — логотип K

## Данные
- localStorage ключ kuda_v1: баланс, траты, чеки, цели, лимиты, ключ Kimi и т.д.
- Миграция v1→v2 встроена (старые данные пользователя сохраняются).
- Данные хранятся на каждом устройстве отдельно (синхронизации пока НЕТ).

## Что УЖЕ работает (v2.0, закоммичено)
Баланс, доходы/траты, чат-ввод «кофе 5 и бензин 40», авто-категории (12 шт),
главное число «Сегодня можно потратить», прогноз остатка до конца месяца,
лимиты с предупреждением 80%, отчёт по месяцам + сравнение с прошлым,
календарь-тепловая карта, AI-советник по экономии, выгрузка Excel (CSV) +
отдельно бизнес-CSV + PDF (печать), архив фото чеков, разбор чеков через
Kimi API (Moonshot, api.moonshot.ai, модель moonshot-v1-32k-vision-preview),
скрин банковской выписки тем же потоком, защита от дублей, сторож гарантий
(14 дней возврата для техники), цели накоплений, повторяющиеся платежи
(авто-списание + напоминание за 3 дня), тревога подорожания, «разделить счёт»
(«ужин 120 на троих» → доля + «Мне должны»), вопросы «сколько на еду в
сентябре», цена в часах работы, USD/EUR с авто-курсом (open.er-api.com),
теги личное/бизнес, языки RU/EN (переключатель в настройках), офлайн PWA,
юр. дисклеймер в настройках.

## Как редактировать файлы через браузер (важно!)
- Создание нового файла: github.com/VizumSystemSale/kuda/new/main →
  focus .cm-content → key_type полного текста → filename через native setter → Commit.
- НЕЛЬЗЯ редактировать большие файлы через edit-страницу (CodeMirror
  виртуализация режет содержимое!). Большой файл: только удалить и создать заново.
- Проверка целостности: fetch raw.githubusercontent.com/VizumSystemSale/kuda/main/<файл> → длина и хвост.
- После коммита GitHub Pages пересобирает сайт ~1 минуту.
